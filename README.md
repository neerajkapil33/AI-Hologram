# NEERAJ AI — Human Hologram

TypeGPU/WebGPU + React + Three.js foundation for the NEERAJ AI full-body hologram.

## Current engine
- TypeGPU/WebGPU holographic background
- Three.js avatar renderer
- Full-body GLB loader at `public/avatar/avatar.glb`
- Embedded animation playback
- Morph-target / viseme hook for ARKit/Oculus-compatible facial data
- Blinking and procedural fallback avatar
- Gesture command interface

## Next integration layers
1. Real Neeraj full-body GLB
2. Mixamo animation library and blending
3. ARKit facial blendshape mapping
4. Oculus viseme mapping
5. Realtime speech-to-text
6. External TTS and realtime lip-sync
7. AI-controlled gaze, expressions and gestures

The repository is the source-of-truth destination for continued development.
